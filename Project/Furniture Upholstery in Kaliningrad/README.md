# Furniture Upholstery in Kaliningrad

## О проекте
Проект по ручному тестированию веб-сайта компании, предоставляющей услуги по перетяжке и ремонту мягкой мебели в Калининграде.

## Область тестирования
В рамках проекта проверялись основные разделы и функциональные возможности сайта:

- Шапка сайта и навигация.
- Главная страница.
- Разделы «Услуги» и «Цены».
- Страница отзывов.
- Портфолио и отображение изображений.
- Форма обратной связи.
- Контактная информация.
- Футер сайта.
- Адаптивность и мобильная версия.

## Выполненные работы
- Подготовлен план тестирования.
- Составлены тест-кейсы.
- Подготовлен чек-лист.
- Проведено ручное тестирование сайта.
- Зафиксированы обнаруженные дефекты.
- Подготовлен отчёт о тестировании.
