# Restoration of Bathtubs

## О проекте

Проект по ручному тестированию веб-сайта компании, предоставляющей услуги по реставрации ванн.

## Область тестирования

В рамках проекта проверялись основные разделы и функциональные возможности сайта:

- Шапка сайта и навигация.
- Главная страница.
- Разделы «Услуги» и «Цены».
- Страница отзывов.
- Портфолио и отображение изображений.
- Форма обратной связи.
- Контактная информация.
- Футер сайта.
- Адаптивность и мобильная версия.

## Выполненные работы

- Подготовлен план тестирования.
- Разработаны тест-кейсы.
- Составлен чек-лист.
- Проведено ручное тестирование.
- Выявленные дефекты зафиксированы в Jira.
- Подготовлен отчёт по результатам тестирования.

## Инструменты

- Jira
- Google Chrome
- Chrome DevTools

## Документация

- Test Plan — план тестирования.
- Test Cases — тест-кейсы.
- Checklist — чек-лист.
