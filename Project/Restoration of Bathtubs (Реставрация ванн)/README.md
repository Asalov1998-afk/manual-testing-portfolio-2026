# Restoration of Bathtubs

## О проекте

Проект по ручному тестированию веб-сайта компании, предоставляющей услуги по реставрации ванн.

## Что проверялось

- Шапка сайта и навигация.
- Главная страница и основные элементы интерфейса.
- Разделы «Услуги» и «Цены».
- Отображение отзывов и видео.
- Портфолио и загрузка изображений.
- Форма обратной связи и валидация полей.
- Контактная информация.
- Футер сайта.
- Якорные ссылки и мобильная версия.

## Результаты тестирования

- Составлен чек-лист для проверки основных разделов сайта.
- Выполнена проверка пользовательских элементов.
- Зафиксированы результаты проверок со статусами OK и Failed.
- Выявленные дефекты задокументированы в Jira.

## Инструменты

- Jira
- Google Chrome
