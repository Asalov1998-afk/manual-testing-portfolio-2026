# Rostelecom

## О проекте

Проект по ручному тестированию веб-сайта «Ростелеком».

## Цель проекта

Проверка основных функций и пользовательских элементов сайта, выявление ошибок и фиксация обнаруженных дефектов.

## Документация

- Checklist.xlsx — чек-лист тестирования.
- Bug Reports — описание обнаруженных дефектов (при наличии).

## Инструменты

- Jira
- Google Chrome
- Chrome DevTools
