# Rostelecom

## О проекте

Проект по ручному тестированию веб-сайта «Ростелеком».

## Выполненные работы

- Функциональное тестирование.
- Проверка пользовательского интерфейса.
- Проверка корректности работы элементов сайта.
- Выявление и документирование дефектов.

## Инструменты

- Jira
- Google Chrome
- Chrome DevTools
