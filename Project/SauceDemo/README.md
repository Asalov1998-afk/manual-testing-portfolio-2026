# SauceDemo — тестирование интернет-магазина

## О проекте

Проект посвящён ручному функциональному тестированию демонстрационного интернет-магазина SauceDemo.

Цель проекта — проверить основные пользовательские сценарии, выявить функциональные и визуальные дефекты, а также подготовить тестовую документацию.

**Тестируемый сайт:** https://www.saucedemo.com/

## Область тестирования

- Авторизация пользователей
- Отображение каталога товаров
- Сортировка товаров
- Добавление и удаление товаров из корзины
- Проверка содержимого и стоимости корзины
- Оформление заказа
- Проверка расчёта стоимости заказа
- Завершение оформления заказа
- Проверка работы различных тестовых аккаунтов

## Тестовая документация

- Тест-план
- Чек-лист (25 проверок)
- Тест-кейсы (16 тест-кейсов)
- Результаты тестирования
- Баг-репорты

## Используемые инструменты

- Test IT — управление тестированием и тестовая документация
- Jira — регистрация и отслеживание дефектов
- Chrome DevTools — анализ и проверка веб-приложения
- Microsoft Excel — работа с тестовой документацией

## Виды тестирования

- Функциональное тестирование
- UI-тестирование
- Негативное тестирование
- Исследовательское тестирование
- Регрессионное тестирование

## Тестовые аккаунты

- standard_user
- locked_out_user
- problem_user
- error_user
- performance_glitch_user
- visual_user

## Статус проекта

Первоначальный набор тест-кейсов создан и выполнен в Test IT. Чек-лист расширяется, обнаруженные дефекты готовятся к регистрации в Jira.
