# SauceDemo --- тест-план функционального тестирования

## 1. Цель тестирования

Проверить корректность работы интернет-магазина SauceDemo, выявить
функциональные ошибки и проблемы пользовательского интерфейса.

## 2. Объект тестирования

Интернет-магазин SauceDemo: https://www.saucedemo.com/

## 3. Область тестирования

-   Авторизация и выход из аккаунта.
-   Каталог и карточки товаров.
-   Сортировка товаров.
-   Добавление и удаление товаров из корзины.
-   Проверка цен и количества товаров.
-   Оформление заказа.
-   Валидация полей формы.
-   Подтверждение заказа.

## 4. Виды тестирования

-   Функциональное.
-   Исследовательское.
-   UI-тестирование.
-   Позитивное и негативное.
-   Проверка валидации форм.

## 5. Тестовое окружение

-   ОС: Windows 10.
-   Браузер: Microsoft Edge.
-   Тип приложения: Web.

## 6. Критерии завершения

-   Выполнены запланированные тест-кейсы.
-   Зафиксированы обнаруженные дефекты.
-   Подготовлен тестовый отчёт.
-   Результаты сохранены в портфолио.
