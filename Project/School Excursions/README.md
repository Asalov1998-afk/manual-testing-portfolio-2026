# Экскурсия для школьников

## О проекте
Ручное тестирование сайта Excursium, предоставляющего услуги по организации экскурсий для школьников.

Сайт: https://excursium.com

## Что тестировалось
В рамках проекта подготовлено 15 тест-кейсов для проверки основных функций сайта:

- Регистрация нового пользователя
- Авторизация на сайте
- Переход в Telegram и связь с компанией
- Проверка номера телефона
- Навигация по разделам сайта
- Раздел «Все экскурсии»
- Контакты и часто задаваемые вопросы
- Просмотр фотографий экскурсий
- Футер сайта
- Фильтры по популярным запросам, классу и стоимости
- Одновременный выбор нескольких фильтров

## Тестовое окружение
- Операционная система: Windows 10
- Браузер: Microsoft Edge
